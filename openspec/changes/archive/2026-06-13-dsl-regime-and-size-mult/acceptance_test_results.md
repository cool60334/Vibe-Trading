## Issues Found & Resolved

### Bug: Wrong regime manifest path in compiled template

**File:** `research/strategies/code/_templates/signal_engine.py.j2`

The template's `_load_regime_series()` function used `here.parents[3] / "manifests"` to locate
`regime_eth.json`. When a compiled engine is placed at `runs/<run_name>/code/signal_engine.py`,
`here.parents[3]` resolves to the repo root (`C:\Users\cool6\Vibe-Trading`), making the path
`<repo_root>/manifests/` — which does not exist.

The correct path is `<repo_root>/research/manifests/`, consistent with the hand-written
`eth_s5_half_size` signal engine.

**Fix applied:** Changed to `here.parents[3] / "research" / "manifests"` in the template.

Without this fix the compiled engine would silently fall back to all-`"neutral"` regime
(no masking), diverging significantly from the hand-written results.
